ভেক্টর: ২০টি সংখ্যাগত সমস্যা

মাঝারি থেকে কঠিন মানের প্রশ্ন। প্রতিটির সম্পূর্ণ সমাধান লুকানো আছে — আগে নিজে চেষ্টা করো, তারপর “সমাধান দেখুন”-এ ট্যাপ করো।

০১মাঝারিলব্ধি ভেক্টর

3 ও 5 একক মানের দুটি ভেক্টরের মধ্যবর্তী কোণ 60°। এদের লব্ধির মান এবং 3-একক ভেক্টরের সাথে লব্ধির অভিমুখ নির্ণয় করো।

সমাধান
  1. লব্ধির মান, R = √(3² + 5² + 2·3·5·cos60°)
  2. R = √(9 + 25 + 30×0.5) = √49 = 7 একক।
  3. অভিমুখ, tanα = 5·sin60° / (3 + 5·cos60°)
  4. tanα = 4.33 / 5.5 = 0.787 ⟹ α ≈ 38.2°
উত্তরলব্ধি = 7 একক, 3-একক ভেক্টরের সাথে ≈ 38.2° কোণে।
০২মাঝারিমধ্যবর্তী কোণ

প্রতিটি 10 একক মানের দুটি সমান ভেক্টরের লব্ধির মানও 10 একক। ভেক্টর দুটির মধ্যবর্তী কোণ নির্ণয় করো।

সমাধান
  1. R² = A² + B² + 2AB·cosθ
  2. 10² = 10² + 10² + 2·10·10·cosθ
  3. 100 = 200 + 200·cosθ ⟹ cosθ = −0.5
  4. θ = 120°
উত্তরমধ্যবর্তী কোণ = 120°
০৩মাঝারিউপাংশ

50 N একটি বল অনুভূমিক রেখার সাথে 37° কোণে ক্রিয়াশীল। এর অনুভূমিক ও উল্লম্ব উপাংশ নির্ণয় করো।

দেওয়া আছেsin37° = 0.6, cos37° = 0.8
সমাধান
  1. অনুভূমিক উপাংশ, Fₓ = 50·cos37° = 50×0.8 = 40 N
  2. উল্লম্ব উপাংশ, F_y = 50·sin37° = 50×0.6 = 30 N
উত্তরঅনুভূমিক = 40 N, উল্লম্ব = 30 N
০৪মাঝারিএকক ভেক্টর

A = 3î − 4ĵ + 12k̂ ভেক্টর বরাবর একক ভেক্টর নির্ণয় করো।

সমাধান
  1. মান, |A| = √(3² + (−4)² + 12²) = √(9 + 16 + 144) = √169 = 13
  2. একক ভেক্টর, Â = A / |A|
উত্তরÂ = (3î − 4ĵ + 12k̂) / 13
০৫মাঝারিস্কেলার গুণফল

A = î + 2ĵ + 3k̂ এবং B = 3î + 2ĵ + k̂ — ভেক্টর দুটির মধ্যবর্তী কোণ নির্ণয় করো।

সমাধান
  1. A·B = (1)(3) + (2)(2) + (3)(1) = 3 + 4 + 3 = 10
  2. |A| = |B| = √(1 + 4 + 9) = √14
  3. cosθ = A·B / (|A||B|) = 10 / 14 = 0.714
  4. θ ≈ 44.4°
উত্তরমধ্যবর্তী কোণ ≈ 44.4°
০৬মাঝারিলম্ব শর্ত

λ-এর কোন মানের জন্য A = 2î + λĵ + k̂ এবং B = 4î − 2ĵ − 2k̂ পরস্পর লম্ব হবে?

সমাধান
  1. লম্ব হলে A·B = 0
  2. (2)(4) + (λ)(−2) + (1)(−2) = 0
  3. 8 − 2λ − 2 = 0 ⟹ 2λ = 6
উত্তরλ = 3
০৭কঠিনভেক্টর গুণফল · ক্ষেত্রফল

A = 3î + ĵ + 4k̂ ও B = î − ĵ + k̂ — এদের সন্নিহিত বাহু ধরে গঠিত সামান্তরিকের ক্ষেত্রফল নির্ণয় করো।

সমাধান
  1. সামান্তরিকের ক্ষেত্রফল = |A × B|
  2. A × B = î(1·1 − 4·(−1)) − ĵ(3·1 − 4·1) + k̂(3·(−1) − 1·1)
  3. = î(1 + 4) − ĵ(3 − 4) + k̂(−3 − 1) = 5î + ĵ − 4k̂
  4. |A × B| = √(25 + 1 + 16) = √42 ≈ 6.48
উত্তরক্ষেত্রফল = √42 ≈ 6.48 বর্গ একক।
০৮কঠিনত্রিভুজের ক্ষেত্রফল

একটি ত্রিভুজের শীর্ষবিন্দু তিনটি A(1, 2, 3), B(2, −1, 1) ও C(3, 2, −1)। ভেক্টর পদ্ধতিতে ত্রিভুজের ক্ষেত্রফল নির্ণয় করো।

সমাধান
  1. বাহু-ভেক্টর, AB = B − A = î − 3ĵ − 2k̂
  2. AC = C − A = 2î + 0ĵ − 4k̂
  3. AB × AC = î((−3)(−4) − (−2)(0)) − ĵ((1)(−4) − (−2)(2)) + k̂((1)(0) − (−3)(2))
  4. = 12î + 0ĵ + 6k̂; |AB × AC| = √(144 + 36) = √180 = 6√5
  5. ক্ষেত্রফল = ½·|AB × AC| = ½·6√5 = 3√5
উত্তরক্ষেত্রফল = 3√5 ≈ 6.71 বর্গ একক।
০৯কঠিনলব্ধির শর্ত

দুটি ভেক্টর A ও B-এর লব্ধি A-এর উপর লম্ব এবং লব্ধির মান B-এর মানের অর্ধেক। A ও B-এর মধ্যবর্তী কোণ নির্ণয় করো।

সমাধান
  1. লব্ধি R = A + B, মধ্যবর্তী কোণ θ।
  2. R ⊥ A ⟹ R·A = 0 ⟹ |A|² + |A||B|cosθ = 0 ⟹ |B|cosθ = −|A| …(i)
  3. |R|² = |A|² + |B|² + 2|A||B|cosθ; (i) বসিয়ে = |A|² + |B|² − 2|A|² = |B|² − |A|²
  4. শর্ত |R| = |B|/2 ⟹ |B|² − |A|² = |B|²/4 ⟹ |A|² = ¾|B|² ⟹ |A| = (√3/2)|B|
  5. (i) থেকে cosθ = −|A|/|B| = −√3/2 ⟹ θ = 150°
উত্তরমধ্যবর্তী কোণ = 150°
১০মাঝারিঅভিক্ষেপ

A = î + 2ĵ + 2k̂ ভেক্টরের B = 2î + ĵ + 2k̂ বরাবর স্কেলার অভিক্ষেপ নির্ণয় করো।

সমাধান
  1. অভিক্ষেপ = A·B / |B|
  2. A·B = (1)(2) + (2)(1) + (2)(2) = 8
  3. |B| = √(4 + 1 + 4) = 3
  4. অভিক্ষেপ = 8 / 3 ≈ 2.67
উত্তরB বরাবর অভিক্ষেপ = 8/3 ≈ 2.67 একক।
১১মাঝারিবলের লব্ধি

একটি বিন্দুতে তিনটি বল ক্রিয়াশীল: F₁ = 2î + 3ĵ, F₂ = −î + 4ĵ, F₃ = 3î − 2ĵ (N)। লব্ধি বলের মান ও x-অক্ষের সাথে অভিমুখ নির্ণয় করো।

সমাধান
  1. ΣF = (2 − 1 + 3)î + (3 + 4 − 2)ĵ = 4î + 5ĵ
  2. মান, |R| = √(4² + 5²) = √41 ≈ 6.40 N
  3. অভিমুখ, θ = tan⁻¹(5/4) ≈ 51.3°
উত্তরলব্ধি ≈ 6.40 N, x-অক্ষের সাথে ≈ 51.3°।
১২মাঝারিভেক্টর বিয়োগ

A = 3î + 2ĵ − k̂ এবং B = î − 3ĵ + 4k̂। (A − B)-এর মান নির্ণয় করো।

সমাধান
  1. A − B = (3−1)î + (2−(−3))ĵ + (−1−4)k̂ = 2î + 5ĵ − 5k̂
  2. |A − B| = √(2² + 5² + (−5)²) = √(4 + 25 + 25) = √54 = 3√6
উত্তর|A − B| = 3√6 ≈ 7.35 একক।
১৩মাঝারিদিক কোসাইন

A = î + ĵ + k̂ ভেক্টরটি x, y ও z অক্ষের সাথে কত কোণ করে?

সমাধান
  1. |A| = √(1 + 1 + 1) = √3
  2. দিক কোসাইন, cosα = cosβ = cosγ = 1/√3 ≈ 0.577
  3. প্রতিটি কোণ = cos⁻¹(1/√3) ≈ 54.7°
উত্তরতিনটি অক্ষের সাথেই ≈ 54.7° কোণ।
১৪কঠিনআপেক্ষিক বেগ

একজন মানুষ 3 m/s বেগে পূর্বদিকে হাঁটছে, আর বৃষ্টি 4 m/s বেগে উল্লম্বভাবে নিচে পড়ছে। মানুষের সাপেক্ষে বৃষ্টির বেগের মান ও দিক নির্ণয় করো।

সমাধান
  1. পূর্ব = +î, উপর = +ĵ ধরি। V_man = 3î, V_rain = −4ĵ।
  2. V_(rain,man) = V_rain − V_man = −3î − 4ĵ
  3. মান = √(3² + 4²) = 5 m/s
  4. উল্লম্বের সাথে কোণ tanθ = 3/4 ⟹ θ = 36.9°
উত্তর5 m/s, উল্লম্বের সাথে ≈ 36.9° কোণে (মানুষের গতির বিপরীতে অর্থাৎ পশ্চিম দিকে হেলানো)।
১৫কঠিনসর্বোচ্চ-সর্বনিম্ন লব্ধি

দুটি বলের সর্বোচ্চ লব্ধি 17 N ও সর্বনিম্ন লব্ধি 7 N। বল দুটির মান নির্ণয় করো এবং এরা পরস্পর লম্বভাবে ক্রিয়া করলে লব্ধি কত হবে?

সমাধান
  1. সর্বোচ্চ লব্ধি P + Q = 17 (কোণ 0°)
  2. সর্বনিম্ন লব্ধি P − Q = 7 (কোণ 180°)
  3. সমাধান করে P = 12 N, Q = 5 N
  4. লম্ব হলে R = √(P² + Q²) = √(144 + 25) = √169 = 13 N
উত্তরP = 12 N, Q = 5 N; লম্ব অবস্থায় লব্ধি = 13 N।
১৬মাঝারিযোগ-বিয়োগ সমমান

যদি |A + B| = |A − B| হয়, তবে A ও B-এর মধ্যবর্তী কোণ নির্ণয় করো।

সমাধান
  1. উভয় পক্ষ বর্গ করে: A² + B² + 2A·B = A² + B² − 2A·B
  2. 4·A·B = 0 ⟹ A·B = 0
  3. |A||B|cosθ = 0 ⟹ cosθ = 0
উত্তরমধ্যবর্তী কোণ = 90° (A ও B পরস্পর লম্ব)।
১৭কঠিনডট ও ক্রস সম্পর্ক

দুটি ভেক্টর A ও B-এর জন্য |A × B| = √3 (A·B) হলে, এদের মধ্যবর্তী কোণ নির্ণয় করো।

সমাধান
  1. |A × B| = |A||B|sinθ, A·B = |A||B|cosθ
  2. শর্ত থেকে |A||B|sinθ = √3·|A||B|cosθ
  3. tanθ = √3 ⟹ θ = 60°
উত্তরমধ্যবর্তী কোণ = 60°
১৮মাঝারিকাজ = F·d

F = 2î + 3ĵ + 4k̂ N বল প্রয়োগে একটি বস্তুর সরণ d = 3î + 4ĵ + 5k̂ m হলে কৃতকাজ নির্ণয় করো।

সমাধান
  1. কৃতকাজ W = F·d
  2. W = (2)(3) + (3)(4) + (4)(5) = 6 + 12 + 20 = 38
উত্তরকৃতকাজ = 38 J
১৯কঠিনটর্ক = r × F

একটি বিন্দুর অবস্থান ভেক্টর r = 3î + 2ĵ − k̂ m এবং প্রযুক্ত বল F = 2î − ĵ + 3k̂ N। ঐ বিন্দুতে টর্ক τ = r × F ও তার মান নির্ণয় করো।

সমাধান
  1. τ = î(2·3 − (−1)(−1)) − ĵ(3·3 − (−1)(2)) + k̂(3·(−1) − 2·2)
  2. = î(6 − 1) − ĵ(9 + 2) + k̂(−3 − 4) = 5î − 11ĵ − 7k̂
  3. মান |τ| = √(5² + 11² + 7²) = √(25 + 121 + 49) = √195 ≈ 13.96
উত্তরτ = 5î − 11ĵ − 7k̂ N·m, |τ| ≈ 13.96 N·m।
২০কঠিনসমান্তরাল একক ভেক্টর

A = 4î − ĵ + 3k̂ ও B = −2î + ĵ − 2k̂। (A + B) ভেক্টরের সমান্তরালে একটি একক ভেক্টর নির্ণয় করো।

সমাধান
  1. A + B = (4−2)î + (−1+1)ĵ + (3−2)k̂ = 2î + 0ĵ + k̂
  2. |A + B| = √(2² + 0² + 1²) = √5
  3. একক ভেক্টর = (A + B) / |A + B|
উত্তর(2î + k̂) / √5
